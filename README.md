This project is a reconstruction of the tecnology used in the wolfestein engine, commonly know as raycasting, were rays are used to undestand how the player should see the world in front of him, leading to the creation of a more faithful 3d enviroment. Therefore our objective is to make a demo showing how such a technology is used and how, we have opted for a simpler aproach making just the basics to show the project in its most basic form.

To begin to use the program we need to compile it, use make in the terminal and execute the created program "cub3d" with a valid map at is side, we procure a few acceptable maps for the program to work in the folder "maps", so a similar command should be used in the terminal "./cub3d maps/good/map_name". When this is executed the game will start, you can move with W A S D, and use the arrow keys to look around. You can exit the game by pressing X on the program window or pressing ESC.

IA was used in our program to support the complexity of the math making the raycasting to give a hand in how it interlock with most of the system and its funtions. We have used a variety of websites explaining how the raycasting process works such as:
